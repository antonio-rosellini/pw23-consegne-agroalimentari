# Pianificazione delle consegne agroalimentari

Project Work n. 23 — Informatica per le Aziende Digitali (L-31)

**Caso di studio:** consegne di un'impresa agroalimentare simulata con deposito a Bari e cinque clienti a Modugno, Bitonto, Triggiano, Noicattaro e Mola di Bari.

Il progetto confronta due configurazioni di flotta mediante enumerazione completa in Python, con vincoli di capacità, analisi dei tempi e dei costi e rappresentazione HTML dei risultati.

## Caricamento iniziale del progetto

La repository è predisposta per importare l'archivio `PW23_Rosellini_GitHub_Pubblico.zip`. Caricare quel file dalla pagina GitHub utilizzando **Add file → Upload files** e confermare con **Commit changes**.

Una procedura GitHub Actions estrarrà i file nelle cartelle corrette e rimuoverà l'archivio dal ramo principale. Quando la procedura sarà completata, questa pagina verrà aggiornata automaticamente con il README completo incluso nel pacchetto.

## Pagina web

Dopo il caricamento, il sito si troverà in `docs/index.html`. Per pubblicarlo: **Settings → Pages → Deploy from a branch → main → /docs → Save**.

Le distanze impiegate sono stime stradali normalizzate riferite ai centri comunali, non misurazioni certificate tra indirizzi specifici.
